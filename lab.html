01 / SIZE

Размер

Большие данные разбиваются на части. Каждая часть путешествует по сети как отдельный пакет.

02 / TTL

Счётчик прыжков

Маршрутизатор уменьшает TTL. Ноль означает, что пакет больше нельзя пересылать.

03 / LOSS

Потери

При потерях часть пакетов не доходит. TCP обычно пытается передать данные снова.

04 / LATENCY

Задержка

Latency показывает, сколько времени занимает путь. Дальний сервер обычно даёт больший RTT.

05 / PROTOCOL

Протокол

TCP, UDP, QUIC и VPN-протоколы по-разному решают задачи доставки и надёжности.

06 / HEADER

Что видит сеть

Маршрутизатору нужна служебная информация, чтобы понять, куда отправить пакет дальше.
