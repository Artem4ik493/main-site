01 / SIZE

Размер → больше пакетов

В этой визуализации большой объём данных превращается в большее количество одновременно летящих пакетов.

02 / TTL

TTL → срок жизни

Каждый hop уменьшает TTL. При TTL = 1 пакет доходит до финального участка и погибает у сервера.

03 / LOSS

LOSS → исчезновение

Когда loss срабатывает, конкретная точка просто гаснет посреди пути — пакет не доходит.

04 / LATENCY

Latency → скорость

Чем выше задержка, тем медленнее движется визуальный поток и тем дольше он добирается до сервера.

05 / PROTOCOL

Protocol → поведение

Протокол меняет подпись и описание симуляции. Сам трафик здесь не настоящий.

06 / HEADER

Заголовок пакета

Служебные поля помогают сети понять, куда и как передавать данные дальше.
